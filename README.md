# PA Politics — public data feed
Machine-generated JSON for the PA Politics app. Updated by `.github/workflows/update.yml` (daily; every 15–30 min around Nov 3, 2026; hourly through Nov 30). Data is committed only when `npm test` passes.
Entry point: `https://raw.githubusercontent.com/sicpoe-wq/pa-politics-data/main/v1/manifest.json`
Sources: PA Department of State (electionreturns.pa.gov), unitedstates/congress-legislators, Open States, Wikipedia, clerk.house.gov, senate.gov, palegis.us, docs.house.gov, U.S. Census.
